# Arte

`gatinho-laco.png` foi preparado a partir de uma imagem de referência fornecida pelo usuário: um gatinho cinza com laço rosa.

A edição foi feita com ImageGen para retirar o fundo branco e a borda, preservando personagem, pose, proporções, cores e estilo.

As molduras, controles e decorações dos temas são desenhados pelo aplicativo em WPF.
